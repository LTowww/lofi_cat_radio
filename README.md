# 🐱 Lo-Fi Cat

Site de fundo relaxante com um gif de gato em tela cheia, rádio lo-fi tocando ao vivo e um texto animado ondulando na tela — feito pra estudar, trabalhar ou só zerar a cabeça.

## ✨ Funcionalidades

- 🎬 Gif de gato em tela cheia como plano de fundo
- 📻 Player de rádio customizado, com estilo lo-fi retrowave, tocando um stream ao vivo da [SomaFM](https://somafm.com/groovesalad/) (Groove Salad)
- 🌊 Texto "JUST CHILL" com efeito de ondulação, como uma bandeira tremulando
- 🎨 Visual estilo synthwave/retrowave (gradientes neon rosa/ciano, brilho, fonte futurista)
- 📱 Totalmente responsivo, ocupando 100% da tela em qualquer dispositivo

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações, filtros SVG, flexbox)
- JavaScript puro (sem frameworks/bibliotecas)

## 🚀 Como rodar

Não precisa de instalação nem servidor — é um site estático simples:

1. Clone o repositório
   ```bash
   git clone https://github.com/SEU-USUARIO/lofi-cat.git
   ```
2. Abra o arquivo `index.html` direto no navegador

## 📻 Créditos

- Áudio: rádio ao vivo [Groove Salad](https://somafm.com/groovesalad/) da [SomaFM](https://somafm.com/) — rádio online gratuita e sem fins lucrativos
- Fonte: [Orbitron](https://fonts.google.com/specimen/Orbitron), via Google Fonts
